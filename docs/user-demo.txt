AKUN DEMO E-OFFICE RSI YATOFA
=============================

Alamat aplikasi : (isi alamat server, mis. https://eoffice.domain-rs.id)
Kata sandi      : sama untuk semua akun demo; lihat EOFFICE_DEMO_PASSWORD di
                  .env.production server (tanyakan ke administrator)
Jumlah akun     : 69 pegawai fiktif, satu atau lebih di setiap unit

Catatan:
- Nama pegawai FIKTIF, hanya untuk latihan dan presentasi.
- Semua login berawalan demo_ dan dihapus sekaligus saat Reset data demo
  (menu Pengaturan Aplikasi) sebelum aplikasi dipakai sungguhan.
- Jangan dibagikan di luar tim; ganti kata sandi bila dipakai lebih luas.
